# Satellite Visualizer

## Feature Plan
### Core
 - [ ] Visual current satellite position in the sky from the perspective of an observer on the ground
 - [ ] Be able to see information about satellite (Number, Name)
 - [ ] Create groups of satellites
    - [ ] Each group has a unique color coding
    - [ ] Be able to filter which groups are being show
    - [ ] If connected to the internet fetch up to date TLEs for each group (if outdated by some configurable threshold)

 - [ ] UI
    - [ ] Controls for filtering what satellites are visible
    - [ ] Show statistics on what satellites are visible (above the horizon)
    - [ ]

### Quest 2
- [ ] Manual calibration of North direction and observer location
### Android Tablet
- [ ] Use sensors to calibrate north and observer location
